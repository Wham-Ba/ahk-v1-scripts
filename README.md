# ahk-v1-scripts

## singlefile.ahk

A file/folder backup utility with a basic GUI. By default, files will be copied into a timestamped folder within the destination directory. Also allows for 'quick- saving/loading' files, meaning that files can be reverted to an earlier state with a simple keypress.

_Makes simple the otherwise clumbersome task of managing game save files._

## OpaqueOnHover_v1.ahk
Toggles the active window to be 'always on-top', and transparent unless hovered over with the mouse.
Primary use-case is studying foreign language VNs while occasionally doing dictionary look-ups.
This is an adaption of a AHKv2 script found on the GameSentenceMiner Discord.

Default hotkeys are (**Ctrl + Alt + 1**) to enable, and (**Ctrl + Alt + 2**) to disable. Holding **Right Alt** can be used to temporarily hide the on-top window.
